# Changelog

## 0.0.1

- Add the initial PersianUI Flutter component library structure.
- Add reusable buttons, cards, display widgets, input fields, and form controls.
- Add feedback and navigation components.
- Add shared design tokens and theme utilities.
- Add a public API entry point.
- Add an example application.
- Add automated tests for components and the public API.
